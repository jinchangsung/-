## 📌 1. 프로젝트 개요 (Executive Summary)

본 프로젝트는 **[비자 정보 플랫폼]**과 **[평생교육원 플랫폼]**의 상호 연계 및 독립 운영을 동시에 달성하기 위한 웹 기반 인터랙티브 와이어프레임 및 기능 명세서(IA/WBS) 시스템입니다.

1. **비자 정보 플랫폼 (VISA Archive)**:
   - **출입국·비자 전문 정보의 지속적인 아카이빙 및 대외 홍보**에 집중.
   - **국문(KO) + 영문(EN)** 다국어 아키텍처를 우선 적용.
   - 공익적 성격에 맞추어 **1차 개발에서는 결제 기능을 배제**하고 최신 법령·지침 고시와 표준 서식 다운로드 및 검색 엔진 구축.

2. **평생교육원 플랫폼 (Life-long Education)**:
   - **전문 교육과정 접수, 다각화 결제 및 온라인 수료증/자격증 발급**을 통한 수익 창출 모델.
   - **일반 유료 과정** 및 **고용보험 환급과정(최대 80% 지원)** 2종 유료 강좌 개설.
   - 1차 개설 3대 핵심 과목: **산재 실무, 비자 행정 실무, 외국인정착설계사(공인 민간자격)**.
   - 카드, 가상계좌(무통장), PayPal을 아우르는 **원스톱 전자결제(PG)** 및 **공식 직인이 날인된 수료증 즉시 인쇄/PDF 저장** 지원.
   - 고도화 동영상 LMS(배속 진도율 80% 산출)는 2단계로 분리 추진.

## 🧭 3. 화면 설계 및 화면 ID 인벤토리 (IA & WBS)

### A. 비자 정보 플랫폼 (Visa Platform)
- **VIS-USR-001 (메인 대시보드)**: 최신 법령/고시 롤링 배너, 주요 공지, 체류자격 퀵내비게이션
- **VIS-USR-010 (체류자격별 안내 뷰어)**: E-7(특정활동), D-8(기업투자), D-2(유학), F-2(거주) 요건, 4단계 발급 절차 인포그래픽
- **VIS-USR-012 (최신 법령·지침 목록)**: 출입국관리법·시행규칙·고시 아카이브, 실시간 제/개정 리스트
- **VIS-USR-013 (법령 상세 및 서식 다운로드)**: 개정 요지, 신구조문대비표 렌더링, 원문 PDF/HWP 다운로드
- **VIS-USR-020 (서비스/조직 소개)**: 법률 조직, 출입국 전문 변호사/행정사 프로필
- **VIS-USR-040 (출입국 서식 자료실)**: [별지 34호] 통합신청서, 고용사유서, 신원보증서 등 서식 모음
- **VIS-USR-050 (홍고자료/영상)**: 언론 보도자료 스크랩 및 브리핑 영상관
- **VIS-USR-060 (소셜 댓글/SNS 공유)**: 비회원 질의응답 및 카카오/X/페이스북/링크 복사 공유
- **VIS-USR-070 (통합 검색)**: 키워드 통합 검색 결과 모달/뷰
- **VIS-ADM-010 (법령/뉴스 CMS 관리)**: 기사 등록 에디터, **국/영문 1:1 매핑 탭**, 태그 설정, 즉시/예약 발행
- **VIS-ADM-040 (소셜 댓글/신고 관리)**: 악성 댓글 모니터링, 신고 누적건 우선 검토, 블라인드/노출 복구

### B. 평생교육원 플랫폼 (Life-long Education Platform)
- **EDU-USR-001 (메인 대시보드)**: 모집 강좌 배너, 3대 과목 카드, 자격시험 D-Day 캘린더
- **EDU-USR-010 (강의소개 탭)**: 일반 유료 vs 고용보험 환급과정 탭 분기, 세부 주차별 커리큘럼(Syllabus)
- **EDU-USR-020 (원스톱 수강신청)**: 신청인 인적사항 및 환급과정 사업자등록번호/기업정보 등록
- **EDU-USR-021 (전자결제 PG 모달)**: 신용카드, 무통장(가상계좌), PayPal 실시간 결제 연동
- **EDU-USR-022 (접수 완료 & 알림톡)**: 고유 접수번호 부여, 전자 영수증 출력, 카카오 알림톡/SMS 모의 확인
- **EDU-USR-030 (자격 종목 안내)**: 외국인정착설계사(1급/2급), 산재실무지도사 취득 로드맵 및 검정 과목
- **EDU-USR-040 (자격시험 일정/접수)**: 회차별 시험 일정표 및 온라인 원서접수 연동
- **EDU-USR-050 (튜터/교수진)**: 현직 공인노무사, 출입국전문 행정사 약력 및 저서 소개
- **EDU-USR-060 (커뮤니티 통합게시판)**: 공지사항, 강의자료실, 수강 후기
- **EDU-USR-070 (나의 접수 내역)**: 신청 강좌 상태 확인, 결제 영수증 재출력, 취소/환불 신청
- **EDU-USR-071 (온라인 증서 출력 센터)**: **공식 직인(재단법인 피플 평생교육원인) 날인 수료증/자격증 고화질 인쇄/PDF 저장**
- **EDU-ADM-001 (운영 대시보드)**: 당일 접수건수, 누적 매출 총액, 과목별 정원 모집률 통계
- **EDU-ADM-010 (개설 강좌 관리 CRUD)**: 신규 강좌 개설(과목명, 일반/환급 구분, 수강료, 정원), 마감 제어
- **EDU-ADM-020 (수강생 접수/결제 관리)**: 과목별 접수자 명단 조회, 결제 대사 확인, **명부 엑셀 일괄 다운로드**
- **EDU-ADM-040 (수료 판정 및 발급)**: 출석률(80% 이상) 기반 일괄 수료 승인 체크, 증서번호 채번 및 출력 권한 제어
- **EDU-ADM-030 (리마인드 알림톡 발송)**: 강좌별 수강생 대상 개강 D-3 일정, 입실시간, 준비물 단체 알림 발송

## 💻 4. 인터랙티브 시스템 주요 특징

1. **3가지 통합 뷰 모드**:
   - **와이어프레임 뷰**: 실제 프로토타입 UI로 탭 전환, 팝업, 결제, 수료증 인쇄 등을 직접 체험.
   - **기능 명세서 (IA & SRS)**: 제안서 첨부 스프레드시트 26개 화면 전체의 UI 컴포넌트, 프로세스, 예외처리를 검색/필터링하고 **CSV 엑셀로 내보내기**.
   - **제안서 요약 & 범위**: 슬라이드 덱 형태의 제안서 요약 및 스코프 매트릭스 프레젠테이션.
2. **반응형 뷰포트 프리뷰**:
   - `데스크톱 (1440px)` / `태블릿 (768px)` / `모바일 (390px)` 디바이스 프레임 시뮬레이션 지원.
3. **기획 스펙 인스펙터 (Spec Drawer)**:
   - 우측 상단 `기획 스펙 보기` 클릭 시, 현재 화면의 상세 기획 주석, 비즈니스 룰, 예외 처리 규칙이 동기화되어 표출.
4. **고화질 브라우저 인쇄 지원**:
   - 공식 직인이 포함된 수료증/자격증 및 전자 결제 영수증은 `Ctrl + P` 또는 화면 내 [인쇄] 버튼을 통해 즉시 실물 크기로 인쇄 및 PDF 저장이 가능합니다.

## 🚀 7. 실행 및 개발 방법 (Getting Started)

### 사전 요구사항
- Node.js 18.0.0 이상
- npm 9.0.0 이상

### 설치 및 로컬 서버 실행

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행 (포트 3000)
npm run dev

# 3. 타입스크립트 린트 검사
npm run lint

# 4. 프로덕션 빌드
npm run build
```

브라우저에서 `http://localhost:3000`으로 접속하여 인터랙티브 와이어프레임 시스템을 확인하실 수 있습니다.
